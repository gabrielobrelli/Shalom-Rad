# Shalom Radiadores — Sistema de Gestão

Sistema web completo para uma oficina de manutenção e recondicionamento de
radiadores, construído em **PHP puro + MySQL** (sem frameworks), pensado
para rodar em hospedagem compartilhada simples.

## Funcionalidades

- 📝 Pedido de clientes **sem necessidade de login/cadastro**, com link
  único para acompanhar o andamento em tempo real
- 🔐 Painel administrativo com login e controle de acesso
- 📋 Gestão de pedidos, com controle de peças prontas/pendentes e múltiplos
  profissionais por item
- 📦 Estoque com número de série, valor por item, filtros de busca e
  alerta automático de estoque baixo
- 🔧 Seção separada para "Concerto de Seminovos"
- 💰 Serviços com múltiplas formas de pagamento (Pix, cartão, dinheiro) e
  conta/maquininha usada
- 🧾 Relatório de fechamento por período (dia, semana, mês, trimestre,
  ano) em PDF, com gráficos
- 💾 Backup completo (site + banco de dados) direto pelo painel
- 🗒️ Quadro de lembretes internos por urgência

## Tecnologias

PHP, MySQL (PDO), HTML/CSS/JS puro — sem frameworks pesados.
